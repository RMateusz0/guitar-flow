# GuitarFlow

**Live demo:** [Try GuitarFlow](https://rmateusz0.github.io/guitar-flow/)

A simple web application for practicing guitar improvisation in B minor.

## Features

- Interactive guitar fretboard
- Guitar note samples
- Backing track playback
- Responsive design
- No external frameworks

## Technologies

- HTML
- CSS
- JavaScript
- Web Audio API

## Run

Open `index.html` in a modern web browser.
